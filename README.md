# LUNEA — Premium Skincare E-Commerce Website

![LUNEA](images/hero/hero-image.png)

> **Take a moment. Make it yours.**

LUNEA is a modern, premium skincare e-commerce website designed to transform everyday skincare into an intentional self-care ritual. The website combines a soft, elegant visual identity with a smooth shopping experience, allowing users to explore skincare collections, discover products, manage their wishlist, add products to a cart, and complete a checkout flow.

The project was created as a front-end web development project using **HTML, CSS, and JavaScript**.

## 🎨 Design

LUNEA's visual identity is inspired by modern luxury skincare brands, combining minimalism, soft colors, elegant typography, and clean product presentation.

## 💾 Data Storage

LUNEA uses the browser's **Local Storage API** to persist selected user data.

The following information can be stored locally:

* Shopping cart items
* Wishlist items
* User profile information

This allows users to navigate between pages without losing their selected products or saved profile information.

> **Note:** This project is a front-end demonstration. It does not currently use a production database, authentication system, or real payment gateway.
